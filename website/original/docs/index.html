Get started with Synapse

A practical guide to the folder structure, commands, and integrations.

Project layout

.synapse/ rules/*.synapse skills/*.skill config.json

Getting started

Install (local dev)

npm install node .\bin\synapse-unified.js --help

Initialize + sync

synapse init synapse sync --all synapse watch

Adapters

Write master rules once, compile to target IDE formats.

Trae output

.trae/rules/*.md

Cursor output

.cursor/rules/*.mdc

Windsurf output

.windsurf/*.windsurfrules

Cline output

.clinerules/*.md

Native binaries

Build standalone executables with pkg (users don’t need Node.js installed).

Build (Windows)

npm install npm run build:binary:win

Release builds

Push a tag like v0.1.0 GitHub Actions builds artifacts

MCP + WebSocket

Expose Synapse to any MCP client (Cursor/Windsurf/Claude Desktop) and any IDE via WebSocket.

MCP server (stdio)

cd standalone npm install npm run build npm start

WebSocket server

cd standalone npm run start:ws GET http://localhost:3457/health POST http://localhost:3457/api/sync

MCP config examples

Cursor: standalone/cursor-mcp-config.json Windsurf: standalone/windsurf-settings.json Claude: standalone/claude_desktop_config.json
