Synapse Documentation

Installation

npm install -g synapse-cli

Quick Start

synapse init
echo '# Rule: My First Rule\nAlways use TypeScript' > .synapse/rules/my-rule.synapse
synapse sync --all

Synapse Rule Format

# Rule: Rule Name
# Description: What this does

Your instructions here

# Constraints:
# @constraint **/*.ts

# Skills:
# @skill code-review

VS Code Extension

Use the extension commands for daily workflows:

Command Palette → Synapse: Initialize Project
Command Palette → Synapse: Sync Rules
Command Palette → Synapse: Analyze Tokens

CLI

Use the CLI for automation and CI:

synapse init
synapse sync --all
synapse watch

Syncing Rules

Synapse keeps one source of truth in .synapse/ and compiles outputs for enabled IDE targets.

.synapse/
  rules/   # master rules
  skills/  # lazy-loaded skills (Pro)

Token Analysis

Analyze token usage and estimated cost per session to find the biggest wins quickly.

Cost Dashboard

Open the “Cost Dashboard” sidebar view to see totals, top rules, and recommendations.

Pro License

Free tier is limited to 2 enabled IDE targets. Pro unlocks:

- Unlimited targets
- Convert large rules to lazy-loaded skills
- Additional Pro-only capabilities

To activate Pro, use:

Command Palette → Synapse: Upgrade to Pro
Enter License Key

MCP + WebSocket

Run standalone servers to integrate with external tools:

cd standalone
npm install
npm run build
npm start       # MCP server
npm run start:ws
