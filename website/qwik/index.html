Token FAQ

Tokens are how AI models measure input and output size. Less tokens usually means lower cost and faster responses.

What is a token?

A token is a small chunk of text (often ~4 characters of English on average). Models bill and enforce limits using tokens, not characters.

How does it affect spending?

Most hosted AI tools charge per token (input + output). If your rules are verbose, every chat includes extra tokens, increasing cost over time.

How Synapse helps

  • Shows token counts in real-time so you can see what’s expensive.
  • Compresses rules safely (including code-block protection) to remove fluff.
  • Pro can fallback to local VS Code models for semantic pruning with 0 API token cost.
