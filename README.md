A tool used to quickly setup rules' files in every development project, used for Trae as IDE.
Use this to save time to interact with AI.


Help
- node .\bin\trae-template.js help

Usage examples

- node .\bin\trae-template.js init C:\project --copy --force --backup
- node .\bin\trae-template.js status C:\project (check exit code for CI)
- node .\bin\trae-template.js sync C:\project --backup
